# Stock Management System

A web-based stock management system built using PHP, MySQL, HTML, CSS, and JavaScript. 

## Features
* **Dashboard:** Overview of the stock and order statistics.
* **Product Management:** Add, edit, and remove products.
* **Categories & Brands:** Categorize items and assign them to specific brands.
* **Order Management:** Manage customer orders and print invoices.
* **Reports:** Generate and view sales reports.
* **User Settings:** Update user details and change passwords.

## Installation / Setup
1. Clone the repository to your local server directory (e.g., `htdocs` for XAMPP or `www` for WAMP).
2. Create a MySQL database and import the provided `stock.sql` file.
3. Update the database connection settings in `php_action/db_connect.php` if necessary.
4. Open the project in your web browser.

## Technologies Used
* **Backend:** PHP
* **Database:** MySQL
* **Frontend:** HTML, CSS, JavaScript, jQuery, Bootstrap
